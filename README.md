# Gautham Paidipala — Personal Portfolio

A modern, high-performance personal portfolio website built with React 19, Vite, and Tailwind CSS v4. Designed to showcase engineering projects, internship experience, skills, and academic achievements with a clean, authentic aesthetic.

Live local development server: `http://localhost:5173/`

---

## 🚀 Tech Stack

* **Frontend**: React 19, JavaScript (ES6+)
* **Styling**: Tailwind CSS v4, Glassmorphism, Ambient Gradients
* **Build Tool**: Vite 8
* **Icons & Animation**: Lucide React, Canvas Confetti

---

## 📌 Featured Sections

* **Hero**: Dynamic tagline, direct resume download, 1-click contact actions, and social profiles.
* **About**: Concise professional summary and contact details.
* **Technical Skills**: Structured categories covering Programming Languages, Web Technologies, Databases & Tools, Software & APIs, AI/ML, and Core CS fundamentals.
* **Projects**:
  * *AI-Based API Test Suite* (Python, Swagger/OpenAPI, REST APIs, JSON, Automated Testing)
  * *Industrial Robotic Arm* (Robotics, Automation, Hardware Integration)
  * *High-Efficiency E-Bike* (Electric Mobility, Battery Management, Hardware)
  * *Urban E-Scooter* (Electric Mobility, Electronics, Power Distribution)
* **Internship Experience**: Technical Intern at Fluxatic Global.
* **Education & Achievements**: Degree details, HSSC/SSC certificates, and competition awards (Converge 3.0, PurpleFest Innovation Challenge, Converge 2.0).
* **Contact**: Direct email with 1-click clipboard copy, phone, location, and validated message form.

---

## 🛠️ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/gauthampaidipala-spec/portfolio.git

# Navigate to project folder
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
